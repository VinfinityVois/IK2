## 💎 О проекте

**Invoice Keeper** — веб-приложение для управления регулярными платежами и финансовыми обязательствами. Оно объединяет удобный интерфейс, серверную обработку данных и хранение информации в единой системе.

## ✨ Возможности

| Возможность | Описание |
|---|---|
| 📅 Регулярные платежи | Организация повторяющихся финансовых обязательств |
| 💰 Финансовые данные | Работа с платежами в едином интерфейсе |
| 🔔 Напоминания | Фоновые задачи и напоминания, если они настроены |
| 🔐 Авторизация | Вход пользователей и контроль доступа |
| 📊 Панель управления | Обзор доступной информации |
| 🗄️ Хранение данных | База данных SQLite |
| ⚙️ Автоматический запуск | Работа служб приложения на сервере |

*Доступные функции зависят от текущей версии и прав пользователя.*

## 🛠️ Технологии

- **Next.js и React** — пользовательский интерфейс.
- **Python и FastAPI** — серверная часть и API.
- **SQLite** — хранение данных.
- **SQLAlchemy** — работа с базой данных.
- **APScheduler** — выполнение фоновых задач.
- **Nginx** — обработка входящих запросов.
- **systemd** — автоматический запуск служб.

## 🔐 Безопасность

- Используй уникальный сложный пароль.
- Не передавай другим пользователям свои учётные данные.
- Не публикуй секретные ключи, пароли и конфигурационные файлы.
- Перед использованием реальных финансовых данных настрой HTTPS.
- Регулярно создавай резервные копии базы данных.
